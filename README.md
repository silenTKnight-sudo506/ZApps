## 💡 Core Philosophy

* **Zero Bloat:** No unnecessary background services, no telemetry, maximum battery efficiency.
* **Card-Driven UI:** Visual, clean, and modern interfaces designed for quick interaction.
* **Local First:** Prioritizing offline functionality and local storage security over cloud dependency.
